# Security Policy

## Reporting a Vulnerability

If you notice a security issue in this portfolio or related demo workflows, please email:

```text
jonzelleotieno31@gmail.com
```

Please include:

- A clear description of the issue
- Steps to reproduce
- Affected URL or file
- Any screenshots or logs that help explain the problem

## Scope

This repository is a portfolio site. Security reports are most useful when they affect:

- Deployed portfolio pages
- Public scripts in this repo
- Exposed credentials or secrets
- Build or deployment behavior
- Links to featured projects

Do not include private credentials, destructive proof-of-concepts, or attempts to access data that is not yours.
