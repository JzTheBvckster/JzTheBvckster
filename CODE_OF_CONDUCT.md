# Code of Conduct

This project uses a simple rule: be clear, respectful, and constructive.

## Expected Behavior

- Be kind and professional.
- Keep feedback specific and useful.
- Respect that this is a personal portfolio.
- Assume good intent, but correct issues directly.

## Unacceptable Behavior

- Harassment, insults, or personal attacks
- Discriminatory language
- Spam or unrelated promotion
- Attempts to expose private data or credentials

## Enforcement

Issues, pull requests, or comments that violate this code may be closed or removed.
